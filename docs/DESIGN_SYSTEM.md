# The Journey — Design System

## Brand
Cinematic at entry, then calm and editorial. Iraq-first, premium, trustworthy and usable.

## Colors
- Night: #070806
- Marsh: #102B23
- Deep green: #1A4538
- Desert sand: #D6C4A3
- Warm paper: #F6F1E8
- Controlled red: #B53A32

Green is structure and atmosphere, not the background of every section. Red is a controlled action accent.

## Typography
- English display: Cormorant Garamond.
- Arabic/UI: Noto Sans Arabic.
- Body fallback: Arial/Helvetica.

## Layout
- Generous editorial spacing.
- Discovery uses horizontal story rails rather than dashboard grids.
- Desktop map is map + results panel.
- Mobile map stacks the map and results.

## Accessibility
- Interactive controls target at least 44px where practical.
- Keyboard focus is always visible.
- Essential functionality never depends on hover.
- Reduced motion bypasses the cinematic intro.
- Arabic uses correct RTL document direction.

## Trust
Verified means details were reviewed against a source. It never means a personal-safety guarantee. Never fabricate missing metadata.

## Motion and performance
- Intro is first-visit only and always skippable.
- Lazy-load MapLibre.
- Avoid autoplay video, heavy WebGL and continuous effects.
- Prefer one strong visual moment over many effects.
